UM MINUTO PARA APRENDER

Cada casa, uma escolha.

Abra todas as casas seguras e coloque uma bandeira em cada mina para vencer.

  1. Revele uma casa. Clique, toque ou use Enter. Seu primeiro clique é seguro.
  2. Leia as pistas. O número conta as minas nas casas vizinhas, incluindo as diagonais. Áreas vazias abrem automaticamente.
  3. Marque as minas. Use o botão direito, a tecla F na casa em foco ou o modo Marcar no celular. Repita para retirar a bandeira.

Use as setas para navegar pelo tabuleiro, Enter ou Espaço para jogar e R para iniciar de novo. Se encontrar uma mina, a partida termina.
